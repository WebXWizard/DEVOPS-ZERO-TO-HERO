# DevOps Fundamentals

## What is DevOps?

DevOps is a culture that combines Development and Operations to deliver software faster and more reliably.

## Goals

- Faster Delivery
- Automation
- Collaboration
- Reliability
- Scalability

## DevOps Lifecycle

Plan → Code → Build → Test → Release → Deploy → Operate → Monitor

## Popular Tools

- Git
- GitHub
- Docker
- Jenkins
- Kubernetes
- Terraform
- AWS
